Arquivos oficiais do logo da kort, em SVG. Cada arquivo tem uma tinta fixa (o `<img>` não herda cor):

- `kort-wordmark.svg`: tinta `#1C1917` (`brand-tinta`), para fundos claros.
- `kort-wordmark-creme.svg`: tinta `#F2EDE6`, para fundos escuros e para `brand-couro`.
- `kort-icone.svg`: o "ko" do logo, ampliado e recortado, em branco sobre `brand-couro`; 120px com cantos de 28px. Ícone do app e favicon no tema claro.
- `kort-icone-escuro.svg`: o mesmo recorte em `#141110` sobre `brand-camurca`, para fundos escuros.

No código React, prefira o componente `Logo`, que segue o tema sozinho.
