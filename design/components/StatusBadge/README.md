Etiqueta do estado de um agendamento: agendado, confirmado, não confirmado, faltou ou cancelado.

- Sempre mostra ícone e palavra. Nunca reduza a uma bolinha colorida: "não confirmado" tem tom vizinho do marrom da marca, e o verde e o vermelho têm a mesma luminosidade.
- "Não confirmado" é a única com contorno tracejado; é o que deixa a etiqueta distinta mesmo para quem não enxerga a diferença de cor.
- "Compareceu" usa `confirmed` com `label="Compareceu"`.
- Não use estas cores para mais nada no painel, e não use `accent` como estado.
